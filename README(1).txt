RideMitra website prototype

1. Upload index.html to Netlify (manual deploy / drag-and-drop).
2. After the site is deployed, open Site configuration > Domain management > Add a domain.
3. Add ridemitra.shop and follow the DNS instructions shown by Netlify.
4. At your domain registrar, update DNS records exactly as Netlify instructs.

Note: This is a front-end demo. Ride listings and booking requests are stored in the visitor's browser only. It does not yet have a shared backend, user authentication, or live multi-user bookings.
